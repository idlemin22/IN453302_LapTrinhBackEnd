# Bài tập thực hành EduHub

Thư mục này gom các bài thực hành đã làm trên lớp.

- `database/01_attendances.sql`: bảng điểm danh, PK/FK và UNIQUE.
- `database/02_queries.sql`: JOIN, GROUP BY/LEFT JOIN và transaction.
- `api/01_huy_dang_ky.md`: API hủy đăng ký và lọc khóa còn chỗ.
- `api/02_tao_thanh_vien.md`: request/response tạo thành viên.
- `api/03_tu_kiem_tra.md`: câu hỏi tự kiểm tra.
- `caching/README.md`: kiến thức caching cơ bản.

Lưu ý: phần project gốc trong file được giữ nguyên. Các bài SQL/API được gom riêng vì project được cung cấp là bài C# Console về SOLID/Design Patterns, chưa phải project Web API có database.
